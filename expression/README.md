# Gene-expression matrices

These are gene-by-sample TPM (transcripts per million) matrices from our ovary and midgut Salmon analyses plus published neurotranscriptome supplements. TPM is normalized expression abundance: a larger value means that gene contributed a larger share of the sample's sequenced transcript pool. These values are not raw integer read counts.

## Files

- `elife_80489_salmon_gene_tpm.tsv.gz`: 19,920 genes × 33 ovary samples generated by us with Salmon 2.4.1 from the Venkataraman et al. (2023) raw FASTQs. The app displays this matrix. The first two columns are `IDs` and `Symbols`; every remaining column is a sample's TPM value.
- `elife_80489_tpm.tsv.gz`: the 18,473-gene published TPM supplement, retained as a source extract but not loaded by the app.
- `neurotranscriptome_2016_aaegl_ru_tpm.tsv.gz`: 16,176 genes × 122 tissue samples using the paper's updated `AaegL.RU` annotation. The first three columns are identifiers/display names.
- `neurotranscriptome_2016_aaegl_3_3_tpm.tsv.gz`: 17,478 genes × 122 tissue samples using the older `AaegL3.3` annotation. The first column is the gene identifier.
- `midgut_nadav_shai_gene_tpm.tsv.gz`: 18,943 genes × 24 midgut samples generated by Salmon through `nf-core/rnaseq` 3.26.0. The first two columns are `gene_id` and `gene_name`; every remaining column is a sample's TPM value.
- `midgut_deseq2/`: seven DESeq2 result tables generated by `nf-core/differentialabundance` 2.0.0 from the Salmon gene-level counts. `contrasts.tsv` records each fixed target/reference comparison; each compressed result table contains the pipeline's `baseMean`, `log2FoldChange`, `lfcSE`, `pvalue`, and `padj` columns for 15,646 tested genes.
- `elife_80489_samples.tsv`: reproductive state, replicate, BioSample accession, and GEO alias for the 33 eLife samples.
- `neurotranscriptome_2016_samples.tsv`: condition, sex, tissue, read length, and mapping metadata from the older paper's library-statistics supplement.
- `neurotranscriptome_2016_gene_annotations.tsv`: paper gene families, OrthoDB categories, Drosophila orthologs/BLASTX hits, and naming evidence for the AaegL.RU genes.
- `midgut_nadav_shai_samples.csv`: condition, sex, blood-feeding timepoint, and replicate metadata for the 24 midgut samples.

For a new UI, use the `AaegL.RU` matrix as the primary representation of the 2016 paper because it is the authors' updated annotation. Retain `AaegL3.3` as an alternate identifier system for compatibility with older mosquito resources.

Rebuild the published supplementary extracts with:

```bash
../scripts/extract_tpm_matrices.py
```

Rebuild the displayed ovary matrix from a validated Salmon output tree with:

```bash
../scripts/build_ovary_salmon_matrix.py \
  /path/to/PRJNA796320_salmon_results \
  elife_80489_samples.tsv \
  elife_80489_salmon_gene_tpm.tsv.gz
```
