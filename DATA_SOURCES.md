# Data sources

The repository includes processed TPM expression matrices and metadata from two open-access studies:

1. Venkataraman K et al. (2023). *Two novel, tightly linked, and rapidly evolving genes underlie Aedes aegypti mosquito reproductive resilience during drought.* eLife 12:e80489. DOI: [10.7554/eLife.80489](https://doi.org/10.7554/eLife.80489). GEO `GSE193470`; BioProject `PRJNA796320`; Zenodo `7758401`. Article and Zenodo materials are CC BY 4.0.
2. Matthews BJ et al. (2016). *The neurotranscriptome of the Aedes aegypti mosquito.* BMC Genomics 17:32. DOI: [10.1186/s12864-015-2239-0](https://doi.org/10.1186/s12864-015-2239-0). BioProject `PRJNA236239`. Article supplementary materials are CC BY 4.0.

It also includes the Nadav Shai / Vosshall lab midgut RNA-seq dataset: 24 paired-end biological libraries spanning non-blood-fed male midgut and female midgut at non-blood-fed, 3, 6, 12, 24, 48, and 72 hours post-blood-meal. The bundled TPM matrix was generated with `nf-core/rnaseq` 3.26.0 and Salmon against the AaegL5 VectorBase 58 + Jové et al. 2019 annotation.

The files under `expression/` contain faithful tabular extracts of the published supplementary tables, the validated gene-level Salmon matrix for the midgut dataset, and seven DESeq2 contrasts produced by `nf-core/differentialabundance` 2.0.0. TPM values are descriptive normalized abundance, not raw read counts; the app displays differential-expression statistics only from the precomputed count-aware pipeline outputs.

## Displayed-data provenance

The three studies do not yet have identical processing provenance:

- The eLife ovary values currently displayed by the app are the published TPM
  supplement. An independent Salmon 2.4.1 reanalysis of `PRJNA796320` has been
  completed against the shared reference below, but its values have not yet
  replaced the published matrix in the app.
- The Matthews et al. neurotranscriptome values currently displayed are the
  authors' published `AaegL.RU` TPM matrix. They retain the paper's annotation;
  ongoing raw-FASTQ reprocessing is tracked separately and is not represented
  as complete in the UI.
- The Nadav Shai midgut TPM matrix and all seven displayed differential-
  expression contrasts were generated by us from the raw paired-end FASTQs.

## Shared raw-FASTQ reference

Our raw-FASTQ analyses use this reference pair:

- Genome: `VectorBase-68_AaegyptiLVP_AGWG_Genome.fasta`
  (AaegL5 / AaegLVP_AGWG), SHA-256
  `fd96bcf4d05fa54b0dc4edeebaf077ab6206c35bda1faa150a392dfdcd0545ec`.
- Gene annotation: `AaegLVP_VB58-Jove19_MT_noS1_geneNames.sorted.gtf`
  (VectorBase 58 with Jové et al. 2019 gene names), SHA-256
  `0bf20c3fae7f8788e44b56fdbc1e81f5dd502da8c4350d5e4c8757a048a74580`.

The completed nf-core midgut run used Trim Galore and Salmon 1.10.3. It did
not perform genomic alignment or produce BAM files: `skip_alignment` was
`true` and `pseudo_aligner` was `salmon`.

## Exact midgut pipeline commands

These commands preserve the original worker paths. Nextflow was pinned to
25.10.7, and both commands used the same local executor configuration.

```bash
export PATH="/opt/conda/bin:/usr/local/bin:$PATH"
export NXF_HOME=/rna/.nextflow
export NXF_VER=25.10.7
export NXF_CONDA_CACHEDIR=/rna/conda
export NXF_TEMP=/rna/tmp
export NXF_OPTS='-Xms1g -Xmx8g'

PROJECT_ROOT=/rna/project/nadav_shai
WORK_ROOT=/rna/work/nadav_shai_nfcore

nextflow run nf-core/rnaseq \
    -r 3.26.0 \
    -profile mamba \
    -c "$PROJECT_ROOT/vast.config" \
    -params-file "$PROJECT_ROOT/nfcore-params.json" \
    -work-dir "$WORK_ROOT" \
    -resume
```

The exact RNA-seq parameter file was:

```json
{
  "input": "/rna/project/nadav_shai/samplesheet.csv",
  "fasta": "/rna/input/Nadav_Shai_Midgut_RNAseq/VectorBase-63_AaegyptiLVP_AGWG_Genome/VectorBase-68_AaegyptiLVP_AGWG_Genome.fasta",
  "gtf": "/rna/reference/AaegLVP_VB58-Jove19_MT_noS1_geneNames.sorted.gtf",
  "pseudo_aligner": "salmon",
  "skip_alignment": true,
  "save_reference": true,
  "max_cpus": 28,
  "max_memory": "170.GB",
  "max_time": "72.h",
  "outdir": "/rna/results/nadav_shai_nfcore"
}
```

Differential expression was run from the resulting Salmon gene-level count and
gene-length matrices:

```bash
export PATH="/opt/conda/bin:/usr/local/bin:$PATH"
export NXF_HOME=/rna/.nextflow
export NXF_VER=25.10.7
export NXF_CONDA_CACHEDIR=/rna/conda
export NXF_TEMP=/rna/tmp
export NXF_OPTS='-Xms1g -Xmx8g'

PROJECT_ROOT=/rna/project/nadav_shai
WORK_ROOT=/rna/work/nadav_shai_differential

nextflow run nf-core/differentialabundance \
    -r 2.0.0 \
    -profile rnaseq,mamba \
    -c "$PROJECT_ROOT/vast.config" \
    -params-file "$PROJECT_ROOT/differential-params.json" \
    -work-dir "$WORK_ROOT" \
    -resume
```

The exact differential-expression parameter file was:

```json
{
  "study_name": "nadav_shai_midgut_rnaseq",
  "study_type": "rnaseq",
  "input": "/rna/project/nadav_shai/observations.csv",
  "contrasts": "/rna/project/nadav_shai/contrasts.csv",
  "matrix": "/rna/results/nadav_shai_nfcore/salmon/salmon.merged.gene_counts.tsv",
  "feature_length_matrix": "/rna/results/nadav_shai_nfcore/salmon/salmon.merged.gene_lengths.tsv",
  "gtf": "/rna/reference/AaegLVP_VB58-Jove19_MT_noS1_geneNames.sorted.gtf",
  "seed": 20260804,
  "outdir": "/rna/results/nadav_shai_differential"
}
```

The seven fixed contrasts were female 3, 6, 12, 24, 48, and 72 hours
post-blood-meal versus non-blood-fed female midgut, plus non-blood-fed male
midgut versus non-blood-fed female midgut. Recorded workflow versions were
nf-core/rnaseq 3.26.0, Salmon 1.10.3, nf-core/differentialabundance 2.0.0,
DESeq2 1.34.0, and Nextflow 25.10.7.
